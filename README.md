# amc-hospital-paper

서울아산병원 **병원보 업무 분석 대시보드**.

호(號)별 편집계획을 받아 담당자별 업무량과 코너·지면 구성을 봅니다.
[언론유닛 홍보 실적 대시보드](https://github.com/daye8965/amc-pr-unit)와 같은 양식입니다.

## 데이터

**데이터는 저장소에 없습니다.** 페이지가 열릴 때 Google Apps Script 엔드포인트를 `fetch` 해서
Google Sheets `★병원보 편집계획안(NEW)` 의 내용을 받아옵니다.

- 탭 하나가 한 호이고, 탭 이름이 호수입니다 (예: `786`)
- 각 탭 상단에 `제786호(12월 1일 자) 콘텐츠 운영 계획`, 그 아래 `지면 | 코너명 | 콘텐츠 | 비고 | 담당` 표
- 실적을 고치려면 저장소가 아니라 **시트를 고쳐야** 합니다

## Apps Script

[apps-script/Code.gs](apps-script/Code.gs) 는 실제로 도는 코드의 **사본**입니다.
여기를 고쳐도 반영되지 않습니다 — Apps Script 편집기에 붙여넣고 재배포해야 합니다.

- 첫 배포: `배포 > 새 배포 > 웹 앱` (실행: 나 / 액세스: 링크가 있는 모든 사용자)
- 이후 수정: `배포 > 배포 관리 > 연필 > 새 버전` — 이렇게 해야 URL 이 유지됩니다
- 배포 전 `testCollect` 를 실행하면 탭 수·호별 건수·담당자별 건수를 로그로 확인할 수 있습니다

## 부서 분석에 쓰는 자료

| 파일 | 무엇 | 다시 만드는 법 |
|---|---|---|
| `org-units.json` | 기구조직도(변경) 2026.10.15부의 조직 201곳 | `python tools/extract-org.py "기구 조직도 변경(안).xlsx"` |
| `doctors.json` | amc.seoul.kr 의료진 1,071명 → 대표 진료과 | `python tools/fetch-doctors.py` |

`org-units.json` 은 `index.html` 의 `ORG_UNITS` 에 **붙여넣어** 쓰고(런타임에 읽지 않음),
`doctors.json` 은 페이지가 열릴 때 **읽습니다**.

기사에 부서를 붙이는 방법은 세 단계입니다.

1. 제목·비고·코너에 **조직 이름이 그대로** 있는 경우 — 긴 이름부터 보므로 `소화기내과`가 `내과`보다 먼저 잡힙니다
2. 비고의 사람 이름이 **의료진 명단**에 있는 경우 — `최영주, 최원묵 (12/8)` → 최원묵 → 소화기내과
3. 1단계로 확정된 기사에서 배운 **직책 붙은 이름**(주임·과장 등) — 부서가 갈리는 이름은 버립니다

확인율은 전체 기간 58%, 2026년 64%입니다. 나머지는 글에 부서 단서가 없거나
독자의 소리·정답 및 당첨자처럼 부서와 무관한 코너입니다.
